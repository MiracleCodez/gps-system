# Thesis Documentation Package

The main downloadable document is [GPS-System-Thesis-Documentation.md](GPS-System-Thesis-Documentation.md). It covers the abstract, introduction, requirements, methodology, system design, implementation, database design, data dictionary, testing plan, limitations, thesis chapter structure, user guide, and reproducibility commands.

## Diagrams

The source diagrams are Mermaid files in `diagrams/`. Rendered PNGs are in `rendered/` and can be inserted into the thesis or presentation:

- `system-context.mmd` — actors, web pages, API, database, and map service
- `system-architecture.mmd` — three-tier architecture
- `use-case.mmd` — administrator and phone-user interactions
- `dfd-level-0.mmd` — level-zero data-flow diagram
- `erd.mmd` — entity relationship diagram
- `sequence-location-update.mmd` — GPS update sequence
- `activity-tracking.mmd` — tracking activity flow
- `deployment.mmd` — local/hosted deployment nodes
